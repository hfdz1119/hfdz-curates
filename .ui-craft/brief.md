## 1. Product purpose

HFDZ Curates（会飞的猪精选）是面向中文用户、带有个人编辑判断的资源导航，帮助用户更快找到真正值得使用、值得回访的工具与知识资源，而不是堆砌链接。

## 2. Primary user

主要用户是希望在桌面或移动设备上快速搜索、浏览分类、判断资源价值并保存个人常用资源的中文互联网工具使用者；首页既服务首次访问时的理解与发现，也服务长期重复访问时的高效检索。

## 3. Three to five principles

1. **编辑判断高于资源数量。** Featured 必须明显高于其他区块，提供“为什么值得”的个人判断；资源数量、标签数量或卡片数量不能替代编辑选择。

2. **先说明价值，再提供去向。** 首页资源卡优先回答“它是什么、为什么值得、去哪里”；平台、授权、难度、网络等完整元信息留在详情页，不让目录卡成为数据库记录。

3. **目录是工具，不是后台。** 搜索、分类、筛选、收藏和数据结构必须保持可用，但页面不引入 KPI、统计卡、无意义图表或传统 Dashboard 布局。全部资源承担目录浏览，Latest 保持低视觉权重。

4. **高密度必须有阅读节奏。** 卡片应共享统一的设计系统，但 Featured、Latest、收藏与全部资源应通过密度、信息层级和编排体现不同角色。限制标签、颜色、阴影与装饰，避免用视觉噪声代替信息层级。

5. **克制的界面应当更快，而非更冷。** 采用 Linear / Raycast 式的深墨中性色主体与暖珊瑚品牌强调色；玻璃效果仅用于轻量层次，动效快速且功能导向，并优先保证加载、搜索和操作响应。

### 页面层级

1. 品牌 Hero：首屏应立即说明“谁做的、精选什么、如何开始”。
2. 搜索与分类：作为最高频入口，支持快速检索与定向浏览。
3. Featured：作为编辑策展主舞台，视觉和内容权重显著高于其他区块。
4. Latest：展示近期录入或更新，保持辅助性、低视觉权重。
5. 我的收藏：服务重复访问，可见但不打断主策展浏览流。
6. 全部资源：承担完整目录浏览与筛选结果承接。

### 响应式与可访问性

- 移动端优先保证搜索、分类切换与资源阅读，不以展示装饰为代价。
- Header 与搜索不得双重 sticky 到挤占过多首屏高度。
- 所有主要触控操作保留至少 44px 目标尺寸。
- 键盘焦点必须完整可见；所有非必要动效尊重 `prefers-reduced-motion`。

## 4. Success metric for the surface

首次访问者应能在首屏快速理解这是会飞的猪制作的编辑精选资源导航，并知道可通过搜索或分类开始。重复访问者应能快速定位资源、判断其是否值得使用或收藏；Featured 必须看起来确实经过编辑选择，而非普通列表置顶。

## 5. Out of scope

- 不做传统 Dashboard，不加入 KPI、统计卡或无意义图表。
- 不使用大面积玻璃拟态、无意义渐变、悬浮缩放或装饰性动效。
- 不使用过多彩色标签；暖珊瑚仅用于品牌、焦点与关键状态。
- 不擅自引入 Three.js、GSAP、WebGL、大型 UI 框架或其他与目标无关的依赖。
- 不为了视觉升级破坏搜索、收藏、筛选、URL 状态同步、JSON/Markdown 数据模型或既有资源详情结构。

## 6. Learned constraints

- **2026-07-16** — 首页必须维持“编辑精选导航”定位，而非资源堆砌或后台管理界面。*Why:* 用户需要快速建立价值判断，而不是处理一批数据。
- **2026-07-16** — 视觉升级以轻量、快速和克制为边界。*Why:* 品牌需要成熟可信的编辑感，不能以通用 AI 模板、炫技动效或重依赖换取表面新鲜感。
- **2026-07-16** — Featured、Latest、收藏和全部资源必须具有清晰且不同的视觉角色。*Why:* 同构卡片会抹平编辑优先级，并使首页读成普通资源库。
