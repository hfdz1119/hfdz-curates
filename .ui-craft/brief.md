## 1. Product purpose

HFDZ Home 是会飞的猪进入个人主页、私人笔记、公开知识库、图片管理和服务状态的统一网页入口。

> 2026-08-15 之前的定位是面向中文用户的 HFDZ Curates 编辑精选资源导航；该能力保留在 `/curates`，但不再定义根首页。

## 2. Primary user

主要用户是会飞的猪本人，在手机或桌面设备上高频、短时访问自己的网页；页面允许其他访客公开访问，但不为陌生访客增加额外内容。

## 3. Three to five principles

1. **自己的入口高于公共目录。** 根首页只展示本人拥有和维护的网页；第三方资源与策展内容退居隐藏的 `/curates`。

2. **一次点击完成到达。** 每个站点入口必须直接、完整可点，不用先搜索、筛选或理解分类。

3. **稳定高于状态装饰。** 入口页不依赖 Uptime Kuma 或其他运行时接口；状态详情由独立状态页承担。

4. **公开不等于暴露。** 只显示安全的公开地址，不展示服务器 IP、后台路径、Token、内部监控数据或凭据。

5. **克制仍要有身份。** 使用深墨中性色和低频 Aurora 光建立 HFDZ 识别度，但不让渐变、玻璃或动效抢过入口本身。

### Superseded Curates principles

以下原则继续约束 `/curates`，但自 2026-08-15 起不再约束根首页：

- 编辑判断高于资源数量。
- 先说明价值，再提供去向。
- 目录是工具，不是后台。
- 高密度必须有阅读节奏。
- 克制的界面应当更快，而非更冷。

## 4. Success metric for the surface

本人进入 `hfdz1119.top` 后，应在首屏立即识别五个站点，并能在一次点击内进入目标页面；移动端无需横向滚动，也不等待任何状态接口。

## 5. Out of scope

- 不在根首页提供第三方资源搜索、分类、收藏或推荐。
- 不展示实时状态、服务器指标、历史趋势或运行日志。
- 不展示后台地址、内部网络信息或任何凭据。
- 不引入与入口管理无关的数据库、服务端接口、状态代理或大型动画依赖。
- 不删除旧 Curates 数据、收藏契约、资源详情或 Git 历史。

## 6. Learned constraints

- **2026-07-16** — `/curates` 必须维持“编辑精选导航”定位，而非资源堆砌或后台管理界面。*Why:* 隐藏保留的资源库仍需让编辑判断高于数据数量。
- **2026-07-16** — 视觉升级以轻量、快速和克制为边界。*Why:* 品牌需要成熟可信，不能以通用 AI 模板、炫技动效或重依赖换取表面新鲜感。
- **2026-07-16** — `/curates` 的 Featured、Latest、收藏和全部资源必须具有清晰且不同的视觉角色。*Why:* 同构卡片会抹平编辑优先级。
- **2026-08-15** — 根首页只放自己的网页，旧策展功能隐藏保留。*Why:* 主域名首先是本人日常进入 HFDZ 子站的家，而不是面向公众扩张的资源平台。
- **2026-08-15** — 第一版不在入口卡片展示实时状态。*Why:* Kuma 数据契约变化不应拖慢或破坏个人入口。
- **2026-08-15** — 首页背景由本人上传替换，不接入随机图片 API。*Why:* 背景内容、版权和加载稳定性应由本人掌控，同时维持纯静态入口的可靠性。
- **2026-08-15** — 入口图标允许显式指定，并以站点 favicon 和 Lucide 依次兜底。*Why:* 自有网页需要准确品牌识别，同时不能让单个图标加载失败破坏入口。
- **2026-08-15** — 保留项目内置背景兜底，同时允许本人粘贴图床 HTTPS 图片直链并保存到当前浏览器。*Why:* 本人可以像更换站点头像一样快速换图，又不需要为公开入口新增后台或数据库。
- **2026-08-15** — 首页提供与个人主页一致的 Aurora、Sakura、Lavender 和 Sunset 四套色彩偏好，但玻璃与卡片主体保持中性。*Why:* HFDZ 各入口需要共享可识别的个人视觉语言，同时不能让多色装饰干扰五个核心入口。
- **2026-08-26** — 入口内容可由本人在私有管理页在线维护，并同步到公开首页。*Why:* 日常新增或调整自有网页不应依赖修改源码和重新发布；管理界面仍须服从首页既有的克制 HFDZ 视觉。
- **2026-08-26** — 自定义背景首页不使用覆盖整组内容的大面积玻璃面板；顶栏、组件、分类和入口卡片各自形成独立毛玻璃层。*Why:* 背景是首页视觉身份的一部分，大面积白灰面会遮掉背景细节，也会削弱玻璃材质的通透层次。
- **2026-08-26** — 网站卡片必须保留背景纹理，不能用过大的模糊半径把图片揉成不透明色块；下拉菜单必须浮在所有玻璃组件之上。*Why:* 通透感来自适度透明和较小局部模糊的组合，层叠错误则会让设置菜单看似掉到内容下面。
- **2026-08-26** — 首页管理入口使用单独的设置图标，不叠加添加图标。*Why:* 该入口覆盖背景、分类、导入和网站管理，不应被误解为只用于新增网站。
- **2026-08-26** — 天气首次加载使用 Cloudflare 访问者地理信息自动定位，浏览器精确定位只在用户主动点击时申请。*Why:* 日常访问应直接显示所在地天气，同时不能自动触发浏览器权限弹窗或存储访客 IP。
